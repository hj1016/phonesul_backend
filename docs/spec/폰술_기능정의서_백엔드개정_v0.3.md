# 폰술 기능정의서 — 백엔드 개정안 (v0.3 / 실시간 건배방 추가)

> **개정 목적:** v0.2의 후순위였던 "실시간 동기화 건배"를 백엔드(FastAPI+wss) 추가로 1차 범위에 편입.
> **개정 범위:** 건배(CH) 영역 확장 + 신규 실시간 방(RT) 영역 추가. 코어(CR)·모드(MD)·검수(SY)는 v0.2 유지.
> **검수:** 이 개정안은 선우(기획) 검수 대상 초안. 하네스 S1 입력으로 쓰기 전 사람 승인 필요.
> ⚠️ 사양 변경: 기존 F-CH-03은 "비동기 링크 매개"였으나, 본 개정으로 실시간 방 방식이 1차에 추가됨(기존 비동기도 폴백으로 유지 가능).

---

## 1. 변경 요약

| 구분 | v0.2 | v0.3(본 개정) |
|---|---|---|
| 건배 방식 | 링크 매개 비동기 "짠" | 비동기 유지 + **실시간 방 "짠" 추가** |
| 백엔드 | 없음(정적/CSR) | **FastAPI 서버(별도 레포) 추가** |
| 통신 | 공유 링크 | **wss 실시간 + 공유 링크** |
| 실시간 동기화 | 후순위(범위 외) | **1차 범위로 편입** |

## 2. 신규/변경 기능 (RT · 실시간 방)

기존 ID 체계(F-{영역}-{번호}) 유지. 신규 영역 코드 **RT**(Realtime Room) 추가.

| 기능 ID | 기능명 | 요약 | 분류 | 우선순위 |
|---|---|---|---|---|
| F-RT-01 | 방 생성 | 주최자가 방 생성 → 서버가 랜덤 코드 발급(방장 권한) | 실시간 | 필수 |
| F-RT-02 | 코드 공유 | 발급 코드를 참여자에게 전달(앱인토스 share 또는 코드 노출) | 실시간 | 필수 |
| F-RT-03 | 방 참여 | 참여자가 코드 입력 → wss 연결로 방 입장 | 실시간 | 필수 |
| F-RT-04 | 인원 동기화 | 입장·퇴장 시 방 인원·목록 실시간 갱신 | 실시간 | 필수 |
| F-RT-05 | 실시간 짠 | 방 안 누구나 "짠" → 전원 화면에 동시 짠 연출(소리·진동) | 실시간 | 필수 |
| F-RT-06 | 방 종료·만료 | 방장 종료 또는 유휴 만료 시 방·상태 폐기 | 실시간 | 필수 |
| F-RT-07 | 재연결 | 소켓 끊김 시 코드로 재입장·상태 복구 | 실시간 | 권장 |

### 변경
- **F-CH-03(건배 수신·연출):** 기존 "비동기 링크 매개" 유지하되, 실시간 방(F-RT-05)이 우선 경로로 추가됨. 방에 들어와 있으면 실시간, 아니면 비동기 폴백.

## 3. 상세 정의

### F-RT-01 · 방 생성
- **입력/트리거:** 주최자가 "건배방 만들기" 선택.
- **처리:** 서버가 Room 생성 + 랜덤 코드(6자, 혼동문자 제외) 발급. 생성자에게 방장 토큰 부여.
  - // ASSUMPTION: 코드 6자·문자셋은 임의값(서버 context §3).
- **출력:** 방 코드 화면 표시 + 공유 버튼.
- **정책:** 코드 추측 남용 방지(시도 제한·만료, 서버 platform §3). // REVIEW(남용 방지).

### F-RT-03 · 방 참여
- **입력/트리거:** 참여자가 코드 입력 후 "참여".
- **처리:** wss 연결 수립 + 코드로 방 식별 → 멤버 등록 → roster 갱신 브로드캐스트.
- **출력:** 방 화면 진입, 현재 인원 표시.
- **정책:** 익명 참여(실명·연락처 저장 금지, 서버 platform §3). // REVIEW(로그인 강제 여부).

### F-RT-05 · 실시간 짠
- **입력/트리거:** 방 안 누구나 "짠" 버튼.
- **처리:** wss로 서버에 cheers 전송 → 서버가 같은 방 전원에게 broadcast → 각 클라이언트 짠 연출.
- **출력:** 전원 화면에 동시 "짠"(잔 부딪힘 연출 + 소리·진동, 설정·무음 종속 — F-SY 승계).
- **비기능:** 체감 지연 최소(목표 수백 ms). // REVIEW(실측). 연타 쿨다운. // ASSUMPTION(쿨다운 값).
- **정책:** 경쟁·순위·집계 금지(비게임). 누가 먼저/많이 짠 표시 금지.

## 5. 범위 밖(후순위 유지)
